## 开始开发

1. 阅读 00、01、07。
2. 让开发 AI 从 S01 开始，使用 07 中的执行模板。
3. 单个阶段完成后记录实现、验证、限制及下一阶段，不把 mock、缺失能力或测试跳过记成完成。
4. 修改已确认范围或契约时同步修改本目录相关文档，保留决策记录。

## 文档优先级

用户当前指令 → 本目录确认的范围与契约 → 可复用材料 → 历史讨论。技术实现可调整，业务条件、状态语义和证据来源必须保持一致。

旧 OpenAPI、旧技术小节写作流程和平台全托管方案不能直接作为当前实现依据。完整索引见 [文档目录](../README.md)。
