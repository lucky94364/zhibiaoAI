# 开发总纲与范围

版本：V2.0；确认日期：2026-11-17。

## 1. 产品目标

帮助售前把招标文件中的选定材料要求，与给定文件夹中的企业、人员、财务和业绩材料核对，展示原文依据，完成补材和局部重检，输出经人工确认的匹配材料清单。

用户已确认采用：**自写 React 前端＋Python 业务后端＋自建解析/OCR与持久存储＋集团平台 AI 工作流**。平台没有文档提取、所需数据库读写和文件持久引用，业务系统负责补齐。

## 2. 业务闭环

1. 创建项目，填写投标主体、负责人、投标截止时间和核验范围。
2. 上传招标文件与材料；保留相对目录，分别登记。
3. 招标线路：解析原文 → AI 提取要求 → 售前修订与确认。
4. 材料线路：解析/OCR → AI 分类和字段提取 → 保存带来源的材料目录。
5. 汇合检查输入版本和处理对账；逐项进行明确条件检查与语义核验。
6. 展示结论、引用页面、缺口和补材建议，允许人工复核。
7. 用户新增或明确替换材料，只解析变更文件；重检全部受影响要求。
8. 输出当前范围的结果表、内容摘录、材料目录及原文件包；用户决定继续或放弃本次投标。

“放弃”是用户明确操作，保存原因与问题，不删除文件或由模型自动决定。

## 3. 首版必做

| 能力 | 首版范围 |
|---|---|
| 项目 | 创建、列表、上下文、范围、状态 |
| 输入 | PDF、PNG/JPG；DOC/DOCX 通过可检测的转换能力接入 |
| 文件 | 原件持久保存、编号、目录、版本、处理进度、原文预览 |
| 解析 | 文字 PDF 提取；扫描页/图片真实 OCR；混合页质量检查 |
| 要求 | 选定条款提取、all/any、角色/阶段、原文引用、修订确认 |
| 材料 | 企业证照、人员证书、财务关键字段、简单业绩合同；来源可追溯 |
| 核验 | supported/partial/missing/contradicted/needs_review；人工状态单独保存 |
| 补材 | 新增、替换、失败不切换旧版本、影响范围计算、局部重检 |
| 输出 | 工作报告 JSON/CSV、材料目录及 ZIP；明确范围和未解决问题 |
| 可观测性 | 持久任务、错误、重试、模型来源标记与确认记录 |

首先跑通已有四项模拟要求，再扩展到公开样本的 5—10 项。企业和人员均使用模拟材料。

## 4. 当前不做

整本标书生成、最终投标文件页码索引、自动报价或联系商家、证书联网验真、信用网站抓取、自动投标决定、完整组织权限、复杂多 Agent、向量数据库、跨项目材料自动共用。

保留接口边界：StoragePort、DocumentParser、OCRProvider、AIWorkflowPort、ExportService；不为未来能力添加不可用业务按钮。

## 5. 成功标准

- 从文件上传到报告导出，通过真实业务 API；刷新及服务重启后项目与原件可恢复。
- 两路处理有独立进度，不需要按顺序上传；核验前要求已确认，材料处理情况明确。
- 初始样本四项分别为：Q01 支持、Q02 证书过期不支持、Q03 支持、Q04 缺合同。
- 替换负责人证书只重新解析新文件，相关项重检后待复核；新增合同能触发原 missing 项。
- 新旧证据和人工决定可追溯；旧任务迟到不会覆盖当前结果。
- 解析失败和材料缺失可区分；没有来源的字段、模型编造引用、未知单位和模糊日期不得成为已支持依据。
- mock 明确标记为模拟；正式联通与 OCR 测试未完成时，不称真实 AI 闭环已验收。

## 6. 团队责任

| 人员 | 责任与验收 |
|---|---|
| Agent 工程师/负责人 | 架构、三条 AI 流程、适配与联调、开发 AI 任务组织 |
| 算法 | 文档解析、OCR、字段和来源提取、质量评测；知识库按需后加 |
| 软开 | 前端、业务 API、数据与文件、任务、版本及重检 |
| 售前 1 | 要求与材料规则、范围、标准答案 |
| 售前 2 | 模拟资料、独立业务复核、反例及验收 |
| 人力 | 时间安排、进度、测试组织、汇报材料 |
| 财务 | 财务字段与条件、反例、岗位相关测试和展示材料 |
| 法务 | 主体及证明形式等岗位规则、反例、相关测试和展示材料 |

AI 可以完成编码，岗位成员仍负责定义正确行为和验收。

## 7. 实现状态口径

- designed：只有文档/契约。
- implemented_mock：业务链路实现，AI 返回来自显式模拟适配。
- integrated：真实组件/API 已联通，有输入输出记录。
- verified：约定样本和反例通过，限制已记录。

四种状态不能互相替代。阶段记录放 `docs/current/progress/`；本轮尚未启动 S01。
