## 验证及结果

以仓库根为起点（本机临时 uv 可替换常规 uv）：

```sh
UV_CACHE_DIR=/private/tmp/zb-uv-cache /private/tmp/zb-uv/bin/uv sync --frozen --offline --project backend
UV_CACHE_DIR=/private/tmp/zb-uv-cache /private/tmp/zb-uv/bin/uv run --frozen --offline --project backend python -m pytest backend/tests -q
cd backend
.venv/bin/alembic upgrade head
.venv/bin/alembic current
cd ../frontend
npm run build
```

- frozen 安装检查通过；pytest 5 passed：JSON Schema 对照、真实模式不回退/不泄密、cwd 无关路径、环境配置、存储与数据库失败降级、CORS 与运行时 OpenAPI。
- Alembic upgrade head/current 退出 0；尚无 revision，不宣称业务迁移验收。
- npm run build（包含 tsc --noEmit）通过；输出 671.23 kB / gzip 216.23 kB，存在 >500kB chunk 提示。
- 前后端均实际启动。8000 已有其他进程，未停止它；后端本次 http://127.0.0.1:8001，前端 http://127.0.0.1:5173，使用 ZB_DEV_API_TARGET=http://127.0.0.1:8001。
- curl 实测 /api/v1/health 返回 ok/0.1.0/UTC 时间；经 5173 代理的 /api/v1/capabilities 返回上述真实状态；前端 HTML 返回正常。
- 初次测试发现中文 SQLite URL 和 Alembic 空格路径问题，修复后复验通过。
